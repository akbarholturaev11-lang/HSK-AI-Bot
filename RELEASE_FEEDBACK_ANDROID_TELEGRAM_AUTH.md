# Release feedback draft — Android Telegram account flow

Status: draft only. Do not send until an admin approves the release.

## Release name

Android’da Telegram orqali akkaunt ochish va ulash

## User message

Android ilovasiga endi Telegram orqali bir qadamda kiring: yangi akkaunt kerak bo‘lsa avtomatik yaratiladi, tilni Telegram’da tanlaysiz va shu qurilmani tasdiqlaysiz. Parol kerak emas.

## Try it

Android ilovasini oching → “Telegram orqali davom etish”ni bosing → Telegram’da tilni tanlang → “Androidni ulash”ni tasdiqlang → HSK AI ilovasiga qayting.

## Feedback and reward

1–5 baho bering. Fikr bildirgan har bir foydalanuvchiga keyingi obuna uchun 10% chegirma beriladi; chegirma shartlari va amal qilish muddati yuborishdan oldin admin tomonidan tasdiqlanadi.

## Target

Android ilovasini birinchi marta ochgan yoki hali Telegram akkaunti ulanmagan foydalanuvchilar.

## Metrics

Android auth screen view → Telegram deep-link open → bot start → language selected → link approved → Android bootstrap success; fallback manual-code rate, link expiry/cancel rate, auth error rate, first lesson start, 1–5 rating and reward redemption.
