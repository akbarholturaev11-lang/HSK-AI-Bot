# Shaxsiy lokal sinov — Ovoz studiyasi

Yuborilmagan draft. Bu HSK bot release’i emas, faqat egasi uchun lokal utilita.

- Yangilik: ruscha/tojikcha matn, tezlik tanlash, offline WAV yaratish va tinglash.
- Qisqa matn: “Ovoz studiyasida ruscha va tojikcha matnni lokal ovozga aylantirish mumkin. Namuna matnni tinglab, talaffuzini tekshiring.”
- Sinab ko‘rish: Start.command → til → Namuna matn → Ovoz yaratish → WAV saqlash.
- Target: ilova egasi, shaxsiy/notijoriy test.
- Baho: “Talaffuz va tushunarlilikni 1–5 baholang. Qaysi so‘z noto‘g‘ri o‘qildi?”
- Reward oldindan: “Bu shaxsiy test; mukofot yoki chegirma ko‘zda tutilmagan.”
- Tasdiq: “Fikringiz qabul qilindi.” Mukofot berilgani da’vo qilinmaydi.
- Kuzatish: ikki tilda muvaffaqiyatli audio ulushi, yaratish vaqti, noto‘g‘ri talaffuz misollari.
