## Asosiy qarorlar

- Kurs uchun asosiy tekshiruv manbasi: **2025-11 HSK考试大纲**, muqovada **2026-07 实施** ko‘rsatilgan.
- `HSK2_2010`, `STANDARD_2021` va `SYLLABUS_2025` materiallari bir versiya hisoblanmaydi.
- 2026-09-20 imtihoni rasmiy e’londa ikkinchi global **pilot** deb atalgan. Barcha markazlar yangi formatga o‘tgan deb aytish uchun dalil yo‘q.
- FLTRP **New HSK Course / 新HSK教程** — yangi rasmiy darslik seriyasi. HSK 1–3 kitoblari topilgan; HSK 4–5 holati kitob katalogida alohida yozilgan.
- To‘liq pullik darslik matni olinmagan va o‘rganib bo‘lingan deb hisoblanmaydi. Hozir rasmiy syllabus, test namunalari, audio va kitob bibliografiyasi jamlangan.
