## Davom ettirish uchun kerak

1. HSK 1–3 bepul sinov tugmalarini ochishga userning aniq ruxsati: HSK 1 trial tugmasi avtomatik UI tekshiruvda hisob/xizmat holatini o‘zgartirishi mumkinligi sabab to‘xtatilgan.
2. Login kerak bo‘lsa, user rasmiy hisobiga kiradi; parol yoki activation code research fayllariga yozilmaydi.
3. To‘liq kirish xarid talab qilsa, aniq mahsulot va summa bo‘yicha alohida user tasdig‘i olinadi.
4. Kirish ochilgach, haqiqiy matn va mashqlar ko‘rilib darsma-dars research qilinadi; oldingi mavzu xaritasi to‘liq kitob bilan solishtiriladi.

Kitobning to‘liq nusxasi mavjud deb aytish uchun avval real ochilgan kontent tekshirilishi kerak. Paywall yoki login chetlab o‘tilmaydi; public sample to‘liq kitob deb nomlanmaydi.
