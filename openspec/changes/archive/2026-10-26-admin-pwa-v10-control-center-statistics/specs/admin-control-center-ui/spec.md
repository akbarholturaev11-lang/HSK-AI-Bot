# Spec Delta

## Purpose

Present the standalone administrator Home and seven Statistics sections using the owner's V10 reference hierarchy with actual analytics and functional existing actions.

## ADDED Requirements

### Requirement: Real V10 control center
Home SHALL present four real KPI cards, a real dated activity chart, actionable review tasks and functional management shortcuts in the supplied V10 composition. It MUST show the actual snapshot age and MUST NOT include demo banners, fabricated task counts, fake growth or success-only handlers.

#### Scenario: Review payment queue
- **WHEN** the administrator opens the payment review task
- **THEN** the actual current protected queue opens and subsequent decisions retain their existing exact passkey/audit protection

### Requirement: Complete seven-tab Statistics
Statistics SHALL retain seven tabs for overview, course/activity, platforms, conversion, finance/AI, sources and report, with real source-bound cards, tracks, tables and charts. Unsupported or absent instrumentation MUST be labeled honestly instead of borrowing another population's values.

#### Scenario: Platform filter changes
- **WHEN** a platform or period changes during an outstanding analytics request
- **THEN** the selected scope controls the final view and a late prior-scope response cannot replace it

### Requirement: Original editor actions
New shortcuts SHALL use existing validated editors and protected actions. An editor MUST preserve the single contextual action, native passkey, cancellation/draft preservation, dirty-state/reversion and short confirmed-success feedback. No duplicate footer dismissal or second confirmation page SHALL be introduced.

#### Scenario: Cancel native authorization
- **WHEN** the administrator cancels a shortcut's native passkey operation
- **THEN** the original unsubmitted editor remains available with its entered data

### Requirement: Localized accessible responsive layout
Home and Statistics SHALL remain readable without horizontal page overflow on mobile and desktop in UZ/RU/TJ. Fixed copy MUST come from canonical catalogs. Focus, keyboard tabs, safe areas, reduced motion and private UI clearing MUST remain functional.

#### Scenario: Mobile Tajik statistics
- **WHEN** the administrator opens every Statistics tab at a 390-pixel viewport in Tajik
- **THEN** real values and labels fit the responsive layout, navigation remains usable and no private data is cached by the browser shell
