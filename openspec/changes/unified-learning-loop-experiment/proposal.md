# Proposal

## Why

The owner and learners are tired of a predictable lesson experience. Accept that qualitative product problem and design a meaningful change: **learn → act in a situation → see a specific demonstrated ability → take the next relevant learning step**. Many existing card types do not disprove experienced sameness. A/B must establish whether the proposed journey improves learning and regular return.

This is a plan-only revision of the existing change/PR, based on GitHub main `d7e91f42851d7823917f62ad04f2faa387a1691c` (2026-11-28), actual queue execution and the owner's private aggregate analytics. [Evidence](evidence.md) separates direct feedback, source findings, observations and gaps. No runtime, migration, production flag or release is changed; private business figures stay outside this public repository.

The owner's active `codex/perf-group2-20261123` is a read-only compatibility reference. Its committed `550343d2`, dirty session-Back snapshot and planned local grading are distinguished in [the integration map](design.md#d11-integrate-with-the-active-performance-work). Latest main `6bc754ea` was compared. Consume those entry/navigation/feedback contracts when available on main rather than implement a parallel version or copy older pages. This task changes only our learning plan, not that branch, plan or work.

## What Changes

- Build **two universal experiential families** using existing material: a coherent two-character audio scene with pause/learner role takeover; and a practical mission requiring independent application, including find/repair/reapply. Translation/choice/builders are response primitives, not extra new formats. Reuse picture practice; open speech remains optional formative work under current quotas.
- Extend the existing planner to preserve core objectives and a useful retrieval opportunity where a legal optional slot exists, then vary contextual practice using goals, verified weakness, time and recent shown history. Short lessons must not grow indefinitely or sacrifice core teaching for novelty.
- Extend current confirmed feedback beyond its first-part-only correction projection. Show demonstrated ability and one relevant existing next action; reuse animations, XP/streak, Mistakes, Word Mastery, Daily Plan and Voice rather than create parallel systems.
- Cover all currently admitted HSK 2.0/3.0 courses, UZ/RU/TJ and requested platforms from the outset. Missing material/old clients receive safe fallback. No rewritten pilot lessons, recruitment or unpublished-level activation.
- Reuse canonical event-store uniqueness for authoritative immutable 50/50 assignment. Add only one bounded neutral exercise receipt store for source snapshots, first responses and help; preserve existing lesson cursors and official completion.
- Compare the coherent journey under a common measurement policy. Primary: seven-day qualified-learning-day count; D1/D7/D14, completion, transfer/recall and satisfaction remain separate. Analyze new/existing cohorts independently; calibrate sample/horizon from real same-definition evidence, without a promised short proof or invented uplift.
- Keep default-OFF delivery, tested 60-second online stop and safe offline lease/base continuation. Internal content/security/device/measurement QA precedes one global 50/50 launch.

## Capabilities

### New Capabilities

- `contextual-course-exercises`: experiential scene/mission families, verified reuse and safe media/platform fallback.
- `course-session-composition`: varied objective-preserving optional practice and stable existing resume.
- `learning-transfer-evidence`: comparable independent evidence, truthful feedback and existing tool continuity.
- `account-learning-experiment`: immutable assignment, interpretable measurement and reversible global delivery.

### Modified Capabilities

None. Existing `admin-real-analytics` privacy/ownership/bounded-read requirements apply unchanged. Adaptive, picture, P3, performance and monitoring plans retain their own ledgers.
