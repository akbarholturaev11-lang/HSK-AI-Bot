# Release feedback draft — Android APK Pro obuna

Holat: draft. Faqat test, deploy va admin tasdig'idan keyin mavjud Release feedback modulida yuborilsin.

## Release nomi

Android APK: to'liq ekran limit va ilova ichida Pro obuna

## Userga qisqa matn

HSK AI Android APK'da limit tugasa, yangi to'liq ekran ochiladi. HSK AI Pro olish, 7 kun bepul sinash (mavjud bo'lsa) yoki Keyinroq tanlash mumkin. Pro bo'limida muddat va to'lov usulini tanlab, chekni ilova ichida yuborasiz. Obuna admin tasdiqlagach ochiladi.

## Nima yangilandi va qayerda sinash

Android APK → Kurs/Mashq/AI Voice'da bepul limitga yeting → “HSK AI Pro olish ⭐” ni bosing → 10 kun, 1 oy yoki 3 oy va kartangiz davlati/yoki Alipay/WeChat'ni tanlang. Haqiqiy to'lov va chek yuborishni faqat staging sinovida test hisob bilan o'tkazing. Trial huquqi bo'lsa 7 kun tugmasi, bo'lmasa Keyinroq tugmasi ishlashini tekshiring.

`Sinab ko'rish` tugmasi `pomp-hsk-ai://course` orqali Android Kurs bo'limini ochsin. Deep link qo'llanmasa, yuqoridagi qisqa yo'riqnoma ko'rsatilsin.

## Baholash

“Android'da limit oynasi va chek yuborish tushunarlimi?” 1 — qiyin, 5 — juda oson.

## Mukofot matni

Baho va qisqa fikr qoldirsangiz, keyingi obuna uchun 20% chegirma beramiz. Tizim mukofotni hisobga qo'shganidan so'ng: “Rahmat! 20% chegirmangiz hisobingizga qo'shildi; Pro obuna narxida ko'rishingiz mumkin.” Yuborishdan oldin admin mukofot qoidasini tasdiqlaydi.

## Target va statistikalar

Target: Android APK'dagi bepul/trial hisoblardan limitga yetganlar, dastlab kichik test guruh. Kuzatish: `android_subscription` manbali `checkout_opened`, `payment_screenshot_submitted`, pending/approved/rejected to'lovlar, admin delivery xatolari, limit → trial va limit → checkout o'tishlari, feedback baholari va 20% chegirma ishlatilishi.
