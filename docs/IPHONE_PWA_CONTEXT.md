## Goal and guardrails

Build the **same** HSK AI learner Telegram Mini App as an **independent iPhone Safari/Home Screen PWA**. Reuse real existing course UI, lesson/grade/progress, account `users.id`, Pro/trial/payment/receipt, locales and services. This is **not** the Admin PWA. Keep Telegram and Android clients intact. No duplicate user/course/billing system, no invented Telegram ID or email auto-merge. Real verified account linking must retain Pro/progress. All graded/protected operations remain server-authoritative. No PWA background Web Push in v1; eventual Smart Reminder PWA is the existing canonical engine's **V2 channel**, not another scheduler. Preserve existing service/account notices separately from daily study reminder limits.
