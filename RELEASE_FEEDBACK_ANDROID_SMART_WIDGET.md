# Release feedback draft — Android Smart Widget

Status: draft only. Do not send until an admin approves the release.

## Release name

Panda Smart Widget — darsni bosh ekrandan eslatadi

## User message

Panda endi Android bosh ekranida: keyingi dars, XP va streakni ilovani ochmasdan ko‘ring. Widget bosilganda native HSK AI ilovasi ochiladi. Xohlasangiz, taxminan 20:00 da keladigan alohida telefon eslatmasini ham yoqing.

## Try it

Profil → Sozlamalar → Panda bosh ekranda → “Widget qo‘shish”. Telefon oynasida qo‘shishni tasdiqlang. Keyin widget chetlarini tortib 2x1, 2x2 yoki 4x2 qiling.

## Feedback and reward

1–5 baho bering. Fikr bildirgan har bir foydalanuvchiga keyingi obuna uchun 10% chegirma beriladi; chegirma shartlari va amal qilish muddati yuborishdan oldin admin tomonidan tasdiqlanadi.

## Target

Android’da kursdan foydalanadigan, kamida bitta darsni boshlagan, native widget hali o‘rnatilmagan foydalanuvchilar.

## Metrics

`android_widget_onboarding_viewed`, `android_widget_pin_requested`, `android_widget_pinned`, `android_widget_opened`, `android_notification_opened`; pin-request → pinned conversion, 7-kun widget retention, widget tap → lesson start, local reminder opt-in, reminder delivery rate, 1–5 rating and reward redemption.
